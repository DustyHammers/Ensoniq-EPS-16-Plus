Ensoniq EPS-16 Plus resources for Windows
=========================================

Place this EPS_files folder beside Ensoniq EPS-16 Plus.vst3 in the Windows
VST3 directory. The usual system-wide layout is:

  C:\Program Files\Common Files\VST3\
    Ensoniq EPS-16 Plus.vst3\
    EPS_files\

Add your legally obtained EPS-16 Plus files to this folder. Firmware and
operating-system images are not distributed with the emulator.

Recognized resource names include:

  eps16plus-rom.bin       combined 128 KiB ROM
  eps16plus-u28.bin       split upper ROM
  eps16plus-u27.bin       split lower ROM
  eps16plus-kpc.bin       KPC keyboard-controller ROM
  EPS130OS.img            EPS operating-system disk image

The plug-in can also locate compatible files by their expected sizes. Start
the DAW and rescan VST3 plug-ins after installing or updating the bundle.
